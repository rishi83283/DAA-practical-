# DAA Practical Repository

Design and Analysis of Algorithms (DAA) practical implementations in Python.

## Practicals Overview

### [Practical 1](./practical%201/) - Sorting Algorithms
- **Bubble Sort**: Best \(O(n)\), Avg/Worst \(O(n^2)\) | Space \(O(1)\)
- **Insertion Sort**: Best \(O(n)\), Avg/Worst \(O(n^2)\) | Space \(O(1)\)
- **Selection Sort**: Best/Avg/Worst \(O(n^2)\) | Space \(O(1)\)
- **Merge Sort**: Best/Avg/Worst \(O(n \log n)\) | Space \(O(n)\)
- **Quick Sort**: Best/Avg \(O(n \log n)\), Worst \(O(n^2)\) | Space \(O(\log n)\)

### [Practical 2](./practical%202/) - Searching Algorithms
- **Linear Search**: Best \(O(1)\), Avg/Worst \(O(n)\) | Space \(O(1)\)
- **Binary Search**: Best \(O(1)\), Avg/Worst \(O(\log n)\) | Space \(O(1)\)

### [Practical 3](./practical%203/) - Heap Sort
- **Heap Sort**: Best/Avg/Worst \(O(n \log n)\) | Space \(O(1)\)

### [Practical 4](./practical%204/) - Factorial
- **Iterative Factorial**: Time \(O(n)\) | Space \(O(1)\)
- **Recursive Factorial**: Time \(O(n)\) | Space \(O(n)\)

### [Practical 5](./practical%205/) - 0/1 Knapsack Problem
- **0/1 Knapsack (Dynamic Programming)**: Time \(O(n \cdot W)\) | Space \(O(n \cdot W)\)

### [Practical 6](./practical%206/) - Matrix Chain Multiplication
- **Matrix Chain Multiplication (Dynamic Programming)**: Time \(O(n^3)\) | Space \(O(n^2)\)

### [Practical 7](./practical%207/) - Making Change Problem
- **Coin Change (Dynamic Programming)**: Time \(O(\text{amount} \cdot \text{len(coins)})\) | Space \(O(\text{amount})\)

### [Practical 8](./practical%208/) - Graph Traversal (BFS & DFS)
- **Breadth First Search (BFS)**: Time \(O(V + E)\) | Space \(O(V)\)
- **Depth First Search (DFS)**: Time \(O(V + E)\) | Space \(O(V)\)

### [Practical 9](./practical%209/) - Prim's Algorithm
- **Prim's Algorithm (MST)**: Time \(O((V + E) \log V)\) | Space \(O(V + E)\)

### [Practical 10](./practical%2010/) - Kruskal's Algorithm
- **Kruskal's Algorithm (MST)**: Time \(O(E \log E)\) | Space \(O(V + E)\)

### [Practical 11](./practical%2011/) - Floyd-Warshall Algorithm
- **Floyd-Warshall (All-Pairs Shortest Path)**: Time \(O(V^3)\) | Space \(O(V^2)\)

### [Practical 12](./practical%2012/) - Travelling Salesman Problem
- **Travelling Salesman Problem (Dynamic Programming)**: Time \(O(n^2 \cdot 2^n)\) | Space \(O(n \cdot 2^n)\)
